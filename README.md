# 生鮮雞肉電商客服 Agent

中央大學 115-1「AI Agent」課程專案 — 單元0：初步構想

## 一、專案背景

家中經營生鮮雞肉訂購生意，目前顧客透過 LINE 官方帳號下單，
需要人工詢問並記錄「姓名 / 電話 / 品項 / 取貨時間」四項資訊，
容易漏問、也佔用大量人力時間。

## 二、初步構想

建立一個 Coze Agent，作為客服的第一線窗口，負責：

- 回答常見問題（品項、部位、價格、保存方式、取貨地點）
- 主動詢問並收集下單所需的四項資訊
- 資訊收集完整後，交由人工確認並成立訂單
- **不由 Agent 直接完成交易或承諾到貨時間**，避免食安與缺貨風險

## 三、使用場景

| 情境 | 顧客輸入範例 | Agent 應對方式 |
|---|---|---|
| 詢問品項 | 「有什麼可以訂？」 | 從知識庫回覆目前販售品項與價格 |
| 下單 | 「我要訂雞胸肉」 | 依序詢問姓名、電話、取貨時間，缺項目就追問 |
| 查保存 | 「雞肉要怎麼保存？」 | 回覆保存建議 |
| 超出範圍 | 詢問醫療/食品安全爭議問題 | 禮貌說明無法回答，導向人工客服 |

## 四、已知限制

- 個資僅用於課程實驗，測試階段一律使用假資料，不會輸入真實顧客電話
- Agent 不具備即時庫存查詢能力，仍需人工最終確認
- 本專案與正在使用的實際 LINE 訂單記錄系統為獨立測試環境
